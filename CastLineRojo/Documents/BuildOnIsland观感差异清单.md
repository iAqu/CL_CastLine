# 对齐 BuildOnIsland 观感差异清单（不改代码版）

## 必做（先补这些，观感会立刻接近）
- 施工顺序规则化：从“按名称排序显现”改为“按层级/模块顺序”（地基 -> 主体 -> 装饰）。
- 飞砖轨迹升级：直线改为轻弧线，加入起飞加速 + 末端减速，避免“硬直线”。
- 显现过渡：部件从透明到可见改为渐显（含 0.1~0.2s 过渡），可叠加轻微缩放弹入。
- 完成态反馈：最后一块落位时增加一次性完成反馈（音效 + 粒子 + 文案提示）。
- 朝向锚点一致性：统一建筑对齐参考点（位置+朝向），避免不同模板出现“偏转感”。

## 可选（中期增强，提升“像同款”的质感）
- 并发飞砖批次：单步 1 块升级为“每批 2~5 块”，并控制最大并发，形成施工繁忙感。
- 阶段节奏变化：不同阶段不同节奏（前期快、后期慢或反之），增加建造过程层次。
- 来源点真实化：飞砖从角色手部/工具附近发射，而非固定 HRP 上方点。
- 材质/颜色过渡：先占位材质，落位后过渡为最终材质，强化“逐步完工”感。
- 区域内视角引导：轻提示“正在建造中”，减少玩家不理解正在发生什么的概率。

## 锦上添花（后期打磨，提升记忆点）
- 里程碑节点反馈：25% / 50% / 75% / 100% 分段特效与提示。
- 特殊块演出：关键节点部件使用独立飞行特效或更强音效（例如主塔顶、门、旗帜）。
- 环境联动：建造进度推进时环境细节同步开启（灯光、旗帜、特效器）。
- 中断恢复表现：离区暂停、回区继续时给“恢复施工”的轻反馈，避免突兀。
- 多玩家可读性：他人也能看到建造进程（可简化表现），增强场景活力。

## 验收口径（用于判断是否“对齐观感”）
- 玩家能肉眼感知“有施工顺序”而不是随机显现。
- 飞砖轨迹看起来“自然且有节奏”，不是机械直线。
- 建筑成形过程有“逐步完成”的层次感，完成时有明显收束反馈。
- 进出区域的开始/暂停/继续过渡自然，不会突兀或失真。
