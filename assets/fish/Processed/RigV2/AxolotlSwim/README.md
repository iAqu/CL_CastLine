# 蝾螈四肢游泳

`#CL_DEV` 的两份 Axolotl 已替换为同一套 20 骨骼资源。四条腿各自有根部和屈伸关节，游泳时后伸并轻微错相随摆，脊椎到尾尖连续左右摆动。网格和五个动作归 M101 Crew。网格 ID 为 `98249488438696`，SwimLoop ID 为 `127927349580825`。

## 验收

- Studio 读回发布网格的 34,434 个顶点。20 根骨骼均有有效权重，24 个滴水点按发布后的实际混合权重绑定。
- 30/60 FPS 采样中，0.4 权重下四只脚始终在各自腿根后方至少 0.26 studs，尾尖横向峰间位移约 1.12 studs。1.0 权重下尾尖约 2.72 studs。长度按模板尺寸测量。
- 160 个实钓阶段采样覆盖五个动作、接嘴和取景。最大取景比例为画框边界的 48.9%。滴水位置误差低于 0.001 studs。
- 新开 Play 验证钓鱼的 0.4 权重和真实池塘控制器的 1.0 权重都播放新 SwimLoop。

## 文件

- `Axolotl.rbxm` 包含两份新版模型和五份可编辑动作源。`Axolotl_before.rbxm` 包含两份替换前模型。两份归档均经过 Studio 回读。
- `models/` 包含 Blender、绑定 FBX 和五个动作 FBX。
- `Axolotl_swim_review.png` 的四行依次为侧视 0.4、侧视 1.0、俯视 0.4、俯视 1.0。每行从左至右是循环的四个采样相位。
- `published.json` 记录资源 ID，`installation.json` 记录回滚路径，其他验收 JSON 保存实际采样。
